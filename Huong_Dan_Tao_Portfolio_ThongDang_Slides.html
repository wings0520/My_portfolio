📥 BƯỚC 1: TÌM & CLONE TEMPLATE TỪ GITHUB

Lấy Mã Nguồn Về Máy (Clone Repository)

Cách 1: Dùng Lệnh Git Clone (Khuyên Dùng)

Mở Terminal (hoặc Git Bash / PowerShell) tại thư mục bạn muốn chứa dự án, gõ lệnh sau: 

# Clone repository về máy tính
git clone https://github.com/wings0520/My_portfolio.git

# Đi vào thư mục vừa tải về
cd My_portfolio
Cách 2: Tải File ZIP (Dành cho người chưa cài Git)

Truy cập trang GitHub của template ➔ Bấm vào nút màu xanh lá cây Code ➔ Chọn Download ZIP ➔ Giải nén thư mục ra ổ đĩa máy tính.

💡 Mẹo Quan Trọng: Ngắt Kết Nối Repo Cũ

Sau khi clone về, thư mục vẫn đang liên kết với tài khoản của tác giả gốc. Bạn cần xóa thư mục ẩn .git để bắt đầu một dự án mới hoàn toàn của bạn: 

# Trên Windows (PowerShell):
Remove-Item -Recurse -Force .git

# Trên Mac / Linux:
rm -rf .git

# Khởi tạo lại Git mới tinh:
git init
🎙️ Gợi ý thuyết trình:
Việc xóa thư mục .git cũ rất quan trọng. Nó giúp bạn không bị xung đột lịch sử commit của người khác và sẵn sàng đẩy lên tài khoản GitHub mang tên chính bạn.
💻 BƯỚC 2: KHẢO SÁT CẤU TRÚC & CHẠY THỬ CỤC BỘ

Khởi Chạy Website Trên Máy Cục Bộ (Localhost)

3 Cách Chạy Thử Ngay Lập Tức
  • Cách 1: Mở thẳng file HTML
    Nhấp đúp vào index.html để mở trên Chrome/Edge (nhanh nhất).
  • Cách 2: Tiện ích Live Server (VS Code)
    Cài Extension Live Server, bấm chuột phải vào index.html ➔ Chọn Open with Live Server. Khi sửa code, trang web sẽ tự động tải lại!
  • Cách 3: Dùng Python HTTP Server
    Mở terminal gõ: python -m http.server 8000 rồi vào http://localhost:8000.

My_portfolio/

├── project 1/       # Chứa 3 ảnh chụp màn hình dự án 1

🎨 BƯỚC 5: TÙY BIẾN HỆ MÀU SẮC & THƯƠNG HIỆU CÁ NHÂN

Đổi Màu Sắc Phù Hợp Với Cá Tính Của Bạn

Cách Đổi Màu Toàn Bộ Trang Web Trong 1 Phút

Tìm khối :root { ... } ở đầu phần <style> trong index.html (khoảng dòng 16 - 31). Bạn chỉ cần thay đổi 2 mã màu chính:

  • Nếu thích phong cách Cyberpunk tím: Giữ nguyên --purple: #A855F7.
  • Nếu thích phong cách Xanh Dương (Công nghệ / FinTech): Đổi thành --purple: #0284C7 (Sky Blue) hoặc #2563EB.
  • Nếu thích phong cách Xanh Lục (Hacker / Sinh thái): Đổi thành --purple: #10B981 (Emerald).
/* Chỉnh sửa mã màu trong index.html */
:root {
  --bg: #09060E;               /* Nền đen */
  --surface: #120B1F;          /* Khối thẻ */
  
  /* Đổi mã màu chính của bạn ở đây: */
  --purple: #0284C7;           /* Màu bạn thích */
  --purple-light: #38BDF8;
  --purple-glow: rgba(2, 132, 199, 0.45);
}

<!-- Sửa logo chữ viết tắt 2 ký tự (Dòng ~2072) -->
<span class="logo-badge">NA</span> <!-- Ví dụ: Nguyễn An -->
🎙️ Gợi ý thuyết trình:
Nhờ hệ thống biến CSS tokenized, bạn không cần phải lục tìm hàng trăm class màu trong file HTML. Chỉ cần đổi 1 biến ở :root, toàn bộ viền phát sáng, nút bấm và gradient chữ sẽ tự động đổi màu theo.

🚀 BƯỚC 10: ĐẨY MÃ NGUỒN LÊN GITHUB CÁ NHÂN

Lưu Trữ Mã Nguồn Bằng Git Terminal

1. Tạo Repository Mới Trên GitHub

Truy cập github.com/new, đặt tên cho kho lưu trữ của bạn (ví dụ: my-portfolio hoặc your-username.github.io), chọn chế độ Public, rồi bấm Create repository.

2. Chạy Các Lệnh Git Sau Trong Terminal:

Lần lượt gõ 5 dòng lệnh sau tại thư mục dự án trên máy tính: 

# 1. Thêm tất cả các file vừa chỉnh sửa
git add .

# 2. Lưu lại bản commit đầu tiên
git commit -m "feat: Launch my new personal portfolio"

# 3. Đổi tên nhánh chính thành main
git branch -M main

# 4. Gắn kết nối tới repo GitHub của bạn
git remote add origin https://github.com/your-username/my-portfolio.git

# 5. Đẩy toàn bộ code lên mạng
git push -u origin main
🎙️ Gợi ý thuyết trình:
Sau khi chạy lệnh git push, toàn bộ code và ảnh của bạn đã được sao lưu an toàn trên đám mây của GitHub. Chúng ta chỉ còn 1 bước cuối cùng để bật trang web lên mạng!
🌐 BƯỚC 11: KÍCH HOẠT GITHUB PAGES (HOSTING MIỄN PHÍ)

Bật Website Trực Tuyến Chỉ Với 3 Cú Click

Quy Trình Bật Hosting Trên GitHub:
  • 1. Vào Settings: Trên trang GitHub của repository vừa tạo, bấm vào tab Settings ở thanh trên cùng.
  • 2. Chọn mục Pages: Ở cột menu bên trái, tìm và bấm vào mục Pages.
  • 3. Chọn nguồn xuất bản (Branch): Tại mục Branch, đổi từ None sang main (thư mục để nguyên /(root)) ➔ Bấm nút Save!

Khi Có Thêm Dự Án Mới, Ta Làm Gì?

Portfolio không phải là thứ làm một lần rồi bỏ xó. Cứ mỗi khi bạn hoàn thành một bài tập lớn, một dự án freelance hay một chứng chỉ mới, hãy cập nhật ngay:

  • Chép ảnh mới vào thư mục projects/.
  • Mở file index.html, sửa lại thông tin dự án trong mảng projects.
  • Mở terminal và gõ 3 câu lệnh Git quen thuộc để đẩy bản mới lên mạng!
# 3 bước cập nhật website bất cứ lúc nào:

# 1. Thêm các thay đổi mới
git add .

# 2. Ghi chú nội dung vừa sửa
git commit -m "update: Add Project 4 & New Certificate"

# 3. Đẩy lên GitHub
git push

# 👉 GitHub Pages sẽ tự động cập nhật web sau 60 giây!
🎙️ Gợi ý thuyết trình:
Chỉ cần nhớ 3 câu lệnh: git add, git commit, git push là bạn có thể cập nhật portfolio của mình mọi lúc mọi nơi một cách chuyên nghiệp như một lập trình viên thực thụ.
